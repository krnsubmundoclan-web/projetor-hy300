Como instalar

INSTALAR

Escolha um jeito

Com um pendrive e o controle do projetor

Baixar APK

  1. Copie o APK num pendrive

    Sem pendrive? Instale o Downloader pela Play Store do projetor e digite este-site/apk

  2. Abra Arquivos

  3. File → pendrive → Projetor.apk

  4. Instalar

  5. Abrir

    Pronto, ele vira a tela inicial

Pelo celular, no mesmo Wi‑Fi do projetor

Baixar instalador

  1. Abra e toque em Procurar

    Antes, ligue o ADB no projetor. Se o Android pedir, permita instalar desta fonte

  2. Instalar o Projetor

    No projetor, aceite "Permitir depuração?"

  3. Pronto

    Desligue o ADB no fim

Pelo computador, com o Claude Code

Repositório ↗

  1. Ligue o ADB no projetor

    Como ligar

  2. Cole no Claude Code

    CARREGANDO

  3. Confirme quando pedir

    No projetor, aceite "Permitir depuração?"

Sem IA: kit para Windows

COMPATIBILIDADE

Qual versão usar?

Aparelho Versão Recomendada Controle Remoto
HY300 / HY300 Mini Shared (Controle Total) Completo (Setas + Home)
HY320 / HY320 Mini Compat (Instalação Segura) Limitado (Home/Voltar via Acessibilidade)
TX6 / X96 / H96 Compat (Instalação Segura) Limitado (Home/Voltar via Acessibilidade)
Outros Android 9+ Shared (Tentar primeiro) Depende do sistema

* O Instalador Inteligente detecta o modelo automaticamente e escolhe a versão correta.

  1. Definições → Preferências do dispositivo

  2. Acerca de

  3. Compilação: OK 7 vezes

  4. Opções de programador → Depuração USB

CONTROLE

Use o celular

  1. Aperte Celular

    Na barra de baixo do projetor

  2. Aponte a câmera

    Mesmo Wi‑Fi, iPhone ou Android

REMOVER

Voltar ao original

  1. Ajustes → Resetar ao original de fábrica

  2. Remover

    Seus apps continuam lá

DÚVIDAS

Compatível: HY300, HY300 Mini, HY320, HY320 Mini, TX6, X96, H96 e projetores Android genéricos (Allwinner/Rockchip) com Android 9+.
Se o sistema for fechado (Tizen/WebOS) ou Android muito antigo, a instalação falhará sem alterar nada.
